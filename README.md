# Atende-mais
Um aplicativo para facilitar o dia a dia de trabalhadores e pessoas, ele ajuda a agendar serviços. Tem funções como agendamento, atendimento, os tipos de serviços que as pessoas desejam, formas de pagamentos, o local; data e hora de onde vai ser os serviços e entre outras. Nesse app tem varios dados com detalhes minimalistas e é super prático.
